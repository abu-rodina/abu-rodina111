# موقع شركة أبو رودينا

## النشر على GitHub Pages
1. أنشئ مستودعًا عامًا جديدًا على GitHub.
2. ارفع جميع الملفات والمجلدات الموجودة هنا إلى جذر المستودع.
3. من Settings ثم Pages اختر Deploy from a branch، وحدد `main` والمجلد `/ (root)` ثم Save.
4. بعد ظهور رابط GitHub Pages، حدّث رابط الموقع في بيانات `url` داخل `index.html`، وحدّث رابط `sitemap.xml`.
